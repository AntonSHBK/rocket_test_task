## План реализации CheckStock

Для реализации проекта будем использовать **Python и FastAPI** для разработки серверной части и REST API, **PostgreSQL** в качестве базы данных, **SQLAlchemy** для работы с базой данных и **Alembic** для управления миграциями. Настройки приложения реализуем через **Pydantic Settings**, веб-интерфейс — на **Jinja2, HTML, CSS и JavaScript**. Для контейнеризации используем **Docker Compose** с облегчённым образом Python Slim, для тестирования — **pytest**.

1\. Настройка Docker

- Создать директорию `Docker`.
- Настроить `Dockerfile` на Python 3.12-slim.
- Настроить `docker-compose.yml` для FastAPI и PostgreSQL.
- Создать `.env` с параметрами окружения.
- Подготовить `requirements.txt`.
- Проверить запуск контейнеров.
